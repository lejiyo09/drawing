# WebPaint Studio

CLIP STUDIO PAINT의 작업 방식을 참고해 만든 브라우저 드로잉 앱입니다. 일러스트·만화·애니메이션 작업을 지원합니다. 빌드 과정이 없고 HTML·CSS·JavaScript만으로 동작하며, 설치(PWA)하면 인터넷 없이도 실행됩니다.

## 실행과 배포

### 로컬에서 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

`index.html`을 파일로 바로 열어도 그리기는 됩니다. 다만 오프라인 설치(서비스 워커)는 `http(s)://`로 열었을 때만 동작합니다.

### Render 배포

저장소에 들어 있는 `render.yaml`이 정적 사이트(Static Site) 설정입니다.

1. [Render](https://render.com) 대시보드에서 **New → Blueprint**를 누르고 이 저장소를 연결합니다. **New → Static Site**를 써도 되는데, 그 경우 Build Command는 비워 두고 Publish Directory는 `.`로 지정합니다.
2. 배포가 끝나면 `https://<이름>.onrender.com` 주소로 접속합니다.
3. `sw.js`와 `index.html`에는 `Cache-Control: no-cache` 헤더가 붙습니다. 그래서 새로 배포하면 사용자에게 "새 버전이 준비되었습니다" 안내가 뜹니다.

> 앱 파일을 고친 뒤 배포할 때는 `sw.js`의 `VERSION` 값을 올려 주세요. 그래야 설치된 앱의 오프라인 캐시가 새 파일로 바뀝니다.

### 오프라인 · 앱 설치(PWA)

- 한 번 접속하면 서비스 워커가 앱 파일 전부(three.js 포함, `vendor/`에 동봉)를 저장합니다. 그다음부터는 인터넷이 끊겨도 실행됩니다.
- 앱으로 설치하는 방법:
  - 데스크톱 Chrome·Edge: 주소창의 설치 아이콘, 또는 앱의 **파일 → 앱으로 설치**
  - 안드로이드: 브라우저 메뉴의 "홈 화면에 추가"
  - iPad·iPhone Safari: 공유 → "홈 화면에 추가"
- 구글 웹 글꼴은 처음 온라인일 때 받아 두고, 오프라인에서는 저장해 둔 글꼴을 씁니다.
- 작업은 브라우저 저장소(IndexedDB)에 3초마다 자동 저장됩니다. 다른 기기로 옮길 때는 **프로젝트 저장(.wpaint)** 이나 PSD를 사용하세요.

## 내보내기

**파일 → 이미지 내보내기 (Ctrl+Shift+S)**

| 형식 | 내용 |
| --- | --- |
| PNG · JPEG · WebP | 보이는 레이어를 합친 한 장 |
| PSD | 레이어·폴더(그룹)·레이어 마스크·합성 모드·불투명도·클리핑·투명 픽셀 잠금·한글 이름. 보정 레이어 중 밝기·대비, 색조·채도·명도, 레벨 보정, 톤 커브, 컬러 밸런스, 계조 반전, 포스터화, 2치화는 PSD 보정 레이어로 들어감 |
| PDF | 모든 페이지를 한 파일로 (만화 원고는 재단선 크기로) |
| ZIP | 모든 페이지를 PNG로 묶음 |
| GIF · WebM/MP4 · PNG 연번 | 애니메이션 (**애니메이션 → 애니메이션 내보내기**) |

- **숨긴 레이어(눈 아이콘을 끈 레이어)는 내보낸 결과에 나오지 않습니다.**
  - PNG·JPEG·WebP·PDF·ZIP·애니메이션에서는 항상 빠집니다.
  - PSD에서도 기본적으로 파일에서 빠집니다. PSD에만 "숨김 상태로 포함" 옵션이 있습니다.
  - 숨긴 레이어에 클리핑된 레이어, 숨긴 폴더 안의 레이어도 함께 빠집니다.
- 밑그림 레이어와 퀵 마스크도 기본적으로 출력하지 않습니다.
- PSD는 **열기**로 다시 불러올 수 있습니다. 폴더·마스크와 위에 나열한 보정 레이어가 복원됩니다.

## 기능

### 그리기
- **펜·연필·붓·에어브러시**: 필압(크기·농도), 손떨림 보정, 입력·출력 보정, 경도, 간격, 종이 질감, 펜 기울기·진행 방향에 따른 브러시 끝 회전
- **물감 혼색**: 불투명 수채, 투명 수채(수채 경계), 유채. 캔버스 색을 집어 섞고 늘입니다.
- **데코레이션 브러시**: 별·하트·꽃·잎·반짝임·눈송이·풀 등. 크기·각도 흔들림과 흩뿌리기를 지원합니다.
- **색 혼합 도구**: 색 혼합, 흐리기, 유동화(밀기·확대·축소·비틀기)
- **지우개**: 래스터 지우개. 벡터 레이어에서는 닿은 부분·교점까지·선 전체 중 골라 지웁니다.
- **기타**: 투명색으로 그리기, Shift+클릭 직선, 채우기(참조 레이어·색의 오차·영역 확대·틈 닫기·에워싸고 칠하기·안 칠한 부분 칠하기), 그라데이션(레이어로 작성 가능), 스포이트

### 레이어
- **종류**: 래스터, 벡터, 텍스트, 폴더, 채우기, 그라데이션, 3D, 보정 레이어 9종(밝기·대비, 색조·채도·명도, 레벨 보정, 톤 커브, 컬러 밸런스, 계조 반전, 포스터화, 2치화, 그라데이션 맵)
- **레이어 마스크**: 작성·편집·끄기·적용·삭제
- **설정**: 아래 레이어에서 클리핑, 합성 모드 17종과 폴더의 "통과", 참조·밑그림·잠금·투명 픽셀 잠금
- **레이어 효과**: 경계 효과(테두리), 레이어 컬러, 톤(스크린톤 망점: 원·선·노이즈)
- **관리**: 결합, 표시 레이어 결합, 래스터화, 레이어 컴프, 드래그로 순서 바꾸기·폴더에 넣기

### 선택·변형
- **선택 범위**: 직사각형·타원·올가미·꺾은선·선택 펜, 자동 선택, 반전·확장·축소·경계 흐리기, 퀵 마스크(Ctrl+M), 선택 범위 저장·불러오기
- **변형**: 확대/축소/회전(Ctrl+T), 자유 변형(Ctrl+Shift+T), 메쉬 변형, 퍼펫 워프. 벡터 선은 픽셀이 아니라 선 데이터를 변형합니다.
- **캔버스**: 캔버스 크기 변경, 해상도 변경, 캔버스 회전·반전
- **필터**: 가우시안 흐리기, 언샤프 마스크, 모자이크, 노이즈, 이동 흐리기, 그리고 모든 보정을 픽셀에 바로 적용

### 벡터
- 펜·도형으로 그린 선을 벡터 데이터로 저장해, 확대해도 다시 그려집니다.
- **오브젝트 도구**: 선 선택(범위 선택 포함), 이동, 선 폭·색 변경, 삭제
- **선 수정 도구**: 제어점, 선 집기, 선 폭 수정, 선 단순화

### 자
- 직선 자, 평행선, 동심원, 방사선, 퍼스 자(1·2·3점), 대칭 자(선 수·선대칭), 가이드
- 스냅 켜고 끄기: 자에 스냅(Ctrl+1), 특수 자에 스냅(Ctrl+2), 그리드에 스냅(Ctrl+3)

### 만화
- **만화 원고**: B5·A4·A5·B4 원고 크기, 재단선·재단 여백·기본 테두리 표시
- **페이지 관리**: 여러 페이지 추가·복제·삭제·순서 변경
- **컷 테두리**: 컷 테두리 폴더 작성, 직사각형 컷, 컷 나누기(좌우·상하 간격, 폴더 분할·테두리만 분할), 꼭짓점 편집
- **말풍선**: 타원·둥근 사각·사각·구름·번쩍. 꼬리를 달 수 있고, 겹친 말풍선은 하나로 이어집니다.
- **텍스트**: 가로·세로쓰기, 한글 글꼴 10종, 글자 테두리
- **효과**: 집중선, 유선, 톤 붙이기

### 애니메이션
- 애니메이션 폴더와 셀, 타임라인에서 셀 지정, 어니언 스킨
- 레이어 키프레임(위치·배율·회전·불투명도), 2D 카메라, 오디오 동기 재생
- GIF, 동영상(오디오 포함), PNG 연번으로 내보내기

### 3D
- 정육면체·구·원기둥·원뿔·토러스·바닥, 관절을 움직이는 데생 인형과 포즈 프리셋
- 표현: 선화·툰·음영. 윤곽선 굵기와 빛 방향을 조절할 수 있습니다.
- 카메라를 회전·이동하고, **카메라로 퍼스 자 작성**으로 3D 카메라에 맞는 소실점을 만듭니다.

### 소재
- 기본 소재: 이미지·패턴, 톤, 브러시 끝, 3D
- 내 소재: 레이어·선택 범위를 이미지 소재나 브러시 끝 모양으로 등록, 현재 보조 도구를 프리셋으로 등록, 이미지 파일 가져오기

## 팔레트 배치

화면 양옆의 보조 도구·도구 속성·컬러 써클·내비게이터·페이지 관리·레이어 속성·레이어·작업 내역 칸을 **팔레트**라고 부릅니다.

- **옮기기**: 팔레트 제목줄을 끌어 왼쪽이나 오른쪽 팔레트 독에 놓습니다. 주황색 선이 들어갈 자리입니다.
- **띄우기**: 독 밖(캔버스 위 등)에 놓거나 제목줄의 ⧉ 버튼을 누르면 떠 있는 창이 됩니다. 오른쪽 아래 모서리로 크기를 바꾸고, ⇲ 버튼으로 다시 독에 붙입니다.
- **접기·펴기**: 제목줄을 클릭합니다.
- **숨기기**: 제목줄의 × 버튼을 누릅니다. 다시 보려면 **창** 메뉴에서 팔레트 이름을 고릅니다.
- **독 너비**: 독과 캔버스 사이 경계를 끌어 조절하고, 더블클릭하면 기본 너비로 돌아갑니다. 독이 비면 접혀서 캔버스가 넓어집니다. 비어 접힌 독에는 화면 가장자리로 팔레트를 끌어 다시 붙입니다.
- 배치는 이 브라우저에 기억되고, **창 → 팔레트 배치 초기화**로 처음 상태로 되돌립니다.

## 알려진 제한

- 클립 스튜디오의 `.clip` 파일은 읽거나 쓸 수 없습니다. PSD로 주고받으세요.
- PSD로 내보낼 때 텍스트·벡터·3D 레이어는 픽셀 레이어로 들어갑니다. 그라데이션 맵 보정 레이어는 병합 이미지에만 반영됩니다. 16비트·CMYK PSD는 열 수 없습니다.
- 동영상 내보내기는 실제 재생 시간만큼 녹화합니다. 출력 형식(WebM 또는 MP4)은 브라우저가 지원하는 것으로 정해집니다.
- 필압과 펜 기울기는 브라우저와 기기가 Pointer Events로 전달하는 값을 씁니다.
