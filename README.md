# WebPaint Studio

CLIP STUDIO PAINT의 작업 방식을 참고해 만든 브라우저용 드로잉 앱입니다. 빌드 과정 없이 HTML·CSS·JavaScript만으로 동작합니다.

## 실행

- `index.html`을 브라우저로 열면 바로 실행됩니다.
- 또는 저장소 폴더에서 `python3 -m http.server`를 실행한 뒤 `http://localhost:8000`에 접속합니다.
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)`를 선택하면 웹 주소로 배포됩니다.

## 내보내기

**파일 > 내보내기 (Ctrl+Shift+S)** 에서 형식을 고릅니다.

| 형식 | 내용 |
| --- | --- |
| PNG | 보이는 레이어를 합친 한 장의 이미지 (투명 배경 유지) |
| PSD | 레이어 구조 유지: 이름(한글 포함), 불투명도, 합성 모드, 클리핑, 투명 픽셀 잠금 + 병합 이미지 |
| JPEG / WebP | 합친 이미지, 품질·크기 조절 |

- **숨긴 레이어(눈 아이콘 끔)는 내보내기에 나타나지 않습니다.** PNG·JPEG·WebP에서는 항상 빠지고, PSD에서도 기본적으로 파일에서 빠집니다. PSD에만 "숨김 상태로 포함" 옵션이 있습니다.
- 숨긴 레이어에 클리핑된 레이어도 화면에서 보이지 않으므로 함께 빠집니다.
- 밑그림 레이어는 클립 스튜디오처럼 기본적으로 출력하지 않으며, "출력에 포함"을 체크하면 들어갑니다.
- 빠른 내보내기: `Ctrl+Shift+E` (PNG), 파일 메뉴의 "PSD로 바로 내보내기".

PSD 파일은 **열기 (Ctrl+O)** 로 다시 불러올 수 있습니다(8비트 RGB, 래스터 레이어. 그룹 폴더는 풀려서 들어옵니다).

## 기능

- **도구**: 돋보기, 손바닥/회전, 레이어 이동, 선택 범위(직사각형·타원·올가미), 자동 선택, 스포이트, 펜(G펜·둥근 펜·밀리펜), 연필, 붓(둥근 붓·평붓), 에어브러시, 지우개, 채우기, 그라데이션
- **브러시 엔진**: 필압(크기·농도), 손떨림 보정, 입력/출력 보정(획의 시작·끝을 가늘게), 경도, 간격, 종이 질감, 투명색으로 그리기, Shift+클릭 직선, 좌우 대칭 자
- **레이어**: 신규·복제·삭제·순서 변경(드래그), 불투명도, 합성 모드 17종, 아래 레이어에서 클리핑, 투명 픽셀 잠금, 레이어 잠금, 참조 레이어, 밑그림 레이어, 용지 레이어, 아래 레이어와 결합, 표시 레이어 결합
- **채우기 / 자동 선택**: 편집 레이어·모든 레이어·참조 레이어 참조, 색의 오차, 영역 확대/축소, 틈 닫기
- **선택 범위**: 추가/삭제, 반전, 확장/축소, 레이어에서 선택 범위(Ctrl+레이어 클릭), 선택 범위 안만 그리기
- **편집**: 확대/축소/회전(Ctrl+T), 좌우·상하 반전, 잘라내기/복사/붙여넣기, 색조·채도·명도, 밝기·대비, 계조 반전, 포스터화, 가우시안 흐리기, 모자이크
- **화면**: 확대·축소·회전·좌우 반전 표시, 내비게이터, 그리드, 두 손가락 제스처
- **작업 내역**: 실행 취소/다시 실행(80단계), 내역 패널에서 원하는 단계로 이동
- **저장**: 브라우저 자동 저장(IndexedDB), 프로젝트 파일(.wpaint) 저장/열기, 이미지 끌어다 놓기·붙여넣기

## 단축키 (클립 스튜디오 기본값 기준)

| 동작 | 키 |
| --- | --- |
| 펜/연필 · 붓/에어브러시 · 지우개 | P · B · E |
| 채우기/그라데이션 · 선택 범위 · 자동 선택 · 스포이트 | G · M · W · I |
| 레이어 이동 · 손바닥 · 회전 · 돋보기 | K · H · R · / |
| 임시 손바닥 · 임시 회전 · 임시 돋보기 · 임시 스포이트 | Space · Shift+Space · Ctrl+Space · Alt |
| 브러시 크기 | [ · ] |
| 실행 취소 · 다시 실행 | Ctrl+Z · Ctrl+Y |
| 신규 래스터 레이어 · 아래 레이어와 결합 · 클리핑 | Ctrl+Shift+N · Ctrl+E · Ctrl+Alt+G |
| 전체 선택 · 선택 해제 · 선택 반전 | Ctrl+A · Ctrl+D · Ctrl+Shift+I |
| 확대/축소/회전 · 색조·채도·명도 · 계조 반전 | Ctrl+T · Ctrl+U · Ctrl+I |
| 피팅 · 100% | Ctrl+0 · Ctrl+Alt+0 |

전체 목록은 앱의 **도움말 > 단축키 목록 (F1)** 에 있습니다.

## 구조

```
index.html      화면 구성
css/app.css     스타일
js/app.js       문서 모델, 합성, 브러시 엔진, 도구, UI
js/psd.js       PSD 읽기/쓰기 (PackBits RLE)
```

클립 스튜디오의 로고·아이콘·소재·`.clip` 파일 형식은 사용하지 않는 독자 구현입니다.
